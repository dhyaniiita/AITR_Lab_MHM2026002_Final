# Prompt Sensitivity and Conclusion Stability in LLMs

**Author:** Dhyan Shah (Enrollment: MHM2026002)
**Institution:** IIIT Allahabad (M.Tech IT, Semester I)

## Research Question
How do compounding error probabilities driven by prompt sensitivity affect the terminal failure rate and stability of research conclusions in LLM-assisted workflows, compared to an independent error baseline?

## Reproducibility
This repository contains the executable Phase 3 Jupyter notebook required to reproduce the Monte Carlo simulation of our 4-stage agentic workflow on the `PubMedQA` dataset using `Qwen2.5` models. 
Please refer to `notebooks/` to run the baseline experiment, and `requirements.txt` for the Colab T4 environment configuration.
